# Подключить ZONA к AI-агенту

ZONA присылает в личный Telegram отчёты от лица девушки: что сделала, что проверила,
каков статус проекта и что осталось. Отправитель работает отдельно от основного бота.

## Одна ссылка для агента

Скопируйте в **Codex, Claude Code или Cursor Agent**:

> Подключи ZONA по https://github.com/divangames/zona/blob/main/skills/zona-reports/SKILL.md для всех моих проектов и чатов в этом агенте. Выполни установку по навыку, сохрани существующие инструкции. После подключения обязательно отправь тестовое сообщение и подтверди ответ Telegram. Если не хватает токена или моего Telegram ID, помоги настроить их локально, не публикуя секреты.

Просто открытая ссылка не даёт агенту доступа к компьютеру: нужны shell, Node.js 18+,
доступ к GitHub и Telegram. Для приватного репозитория нужен доступ к нему.
Обычный веб-чат без выполнения команд не сможет установить отправитель.

## Установка вручную

```sh
git clone https://github.com/divangames/zona.git
cd zona
npm ci
```

Создайте `.env` в корне ZONA (или дополните существующий, сохранив остальные параметры):

```dotenv
TELEGRAM_BOT_TOKEN=YOUR_BOT_TOKEN
TELEGRAM_OWNER_CHAT_ID=YOUR_NUMERIC_PRIVATE_CHAT_ID
```

Токен получите у @BotFather, личный числовой ID — например, у @userinfobot.
Сначала отправьте своему боту `/start` в личном чате. Не вставляйте токен в Git,
публичный чат или аргументы команды. `.env` исключён из Git. ID и токен автора
репозитория не включены: каждый владелец настраивает собственного получателя.

Выберите клиент:

```sh
node scripts/install-reporting.js --client codex
node scripts/install-reporting.js --client claude
node scripts/install-reporting.js --client cursor
```

| Клиент | Что устанавливается | Область действия |
|---|---|---|
| Codex | `~/.codex/skills/zona-reports`, глобальный `AGENTS.md` либо активный `AGENTS.override.md`; учитывается `CODEX_HOME` | Все чаты, загрузившие инструкции на этом ПК |
| Claude Code | `~/.claude/skills/zona-reports`, блок в `~/.claude/CLAUDE.md` | Все проекты и чаты, загрузившие инструкции |
| Cursor | `~/.cursor/skills/zona-reports`, текст `~/.cursor/zona-reporting-user-rule.md` | Для всех чатов вставьте сгенерированный текст в **Settings → Rules → User Rules** |

У Cursor глобальные User Rules не являются обычным файлом правил. Установщик
не изменяет внутреннюю базу настроек. Для текущего проекта можно добавить
постоянное правило автоматически:

```sh
node scripts/install-reporting.js --client cursor --project "/absolute/path/to/project"
```

Создаётся `.cursor/rules/zona-reports.mdc` с `alwaysApply: true`. Один глобальный
навык без постоянного правила не означает автоматический отчёт в каждом чате.

Существующие инструкции сохраняются; блок ZONA обновляется по маркерам,
перед изменением непустого файла создаётся резервная копия. Если перемещаете
папку ZONA, запустите установщик снова: инструкции содержат абсолютный путь.

## Обязательное тестовое сообщение

```sh
node scripts/test-reporting.js
```

Это **реальная отправка**, не предпросмотр. Установка подтверждена, когда команда
пишет «Telegram подтвердил отправку» и вы получаете сообщение от ZONA.
Затем откройте новый чат или обновите сессию агента и выполните небольшую задачу,
чтобы проверить применение постоянного правила.

Каждый ПК, удалённый агент и профиль настраиваются отдельно. На другом компьютере
снова клонируйте репозиторий, заполните локальный `.env`, запустите установщик и тест.
Глобальные инструкции не переносятся вместе с Git-репозиторием автоматически.

## Формат отчёта и ограничения

Образец: [reports/example.json](reports/example.json). Агент записывает отдельный
JSON с UUID вне Git и вызывает отправитель по абсолютному пути:

```sh
node /absolute/path/to/zona/scripts/send-project-report.js /absolute/path/to/report.json --dry-run
node /absolute/path/to/zona/scripts/send-project-report.js /absolute/path/to/report.json
```

`--dry-run` только показывает оформление. Успешная реальная отправка подтверждает
доставку API, но не прочтение владельцем. При частичной отправке команда указывает
число доставленных частей; не повторяйте весь отчёт без проверки, чтобы не дублировать их.

Отчёт формирует агент по инструкциям. Это **не фоновый монитор завершения чатов**:
прошлые задачи не отправляются задним числом, а ограниченная среда, недоступная сеть
или не загруженные инструкции могут помешать отправке. Не запускайте `npm start`
ради отчётов: это запустит основной бот и может конфликтовать с polling на VPS.

Ошибки: `400` — проверьте ID и `/start`; `401` — токен; `403` — бот заблокирован
или не может писать этому получателю. Сетевые ошибки требуют проверки доступа
к Telegram. Не публикуйте полный объект ошибки с токеном.
