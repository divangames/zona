# Отчёты владельцу от ZONA

После выполнения задач пользователя в этом проекте:

1. Подготовь `reports/current.json`: title и непустые массивы строк completed, checks, projectStatus, deployment, issues, nextSteps.
2. Пиши от лица ZONA в женском роде: «я добавила», «проверила», «подготовила». Используй конкретные факты. Полный статус охватывает функции бота, каталог, AI, интеграции, проверки и публикацию. Непроверенное явно отмечай; не выдавай наличие настройки за работоспособность.
3. Указывай выполненные и невыполненные задачи, результаты проверок, ограничения и следующие шаги. Не включай токены, пароли, содержимое .env и персональные данные.
4. Проверь оформление: `npm run report -- reports/current.json --dry-run`.
5. Отправь владельцу личный отчёт: `npm run report -- reports/current.json`. Пользователь явно запросил такие уведомления. Команда не запускает polling и может работать одновременно с ботом на VPS.
6. Если TELEGRAM_OWNER_CHAT_ID отсутствует, запроси числовой Telegram ID. Не выбирай получателя из случайных обновлений и не отправляй отчёты в группы. Если доставка не подтверждена, сообщи об этом пользователю. Не утверждай, что отчёт доставлен, по одному лишь dry-run.

Это правило выполняется агентом при работе с проектом; сам Telegram-бот не наблюдает за завершением чатов Codex.
