# ZonaDeck — запуск с Ollama

Пошаговая инструкция для команды. Обновляйте этот файл при изменении бота.

## 1. Модели Ollama (один раз)

Установите [Ollama](https://ollama.com), запустите приложение (иконка в трее).

В PowerShell или CMD:

```bash
ollama pull llava
ollama pull llama3.2
```

| Модель | Назначение |
|--------|------------|
| `llava` | Распознавание фото кроссовок |
| `llama3.2` | Название и описание в стиле каталога |

Альтернативы: `llama3.2-vision`, `moondream` (фото); `qwen2.5`, `gemma2` (текст).

## 2. Настройка проекта

1. Папка проекта: `f:\Программирование\zona`
2. `start.bat` → **4** — создать `.env` из примера
3. Заполните `.env`:

```env
TELEGRAM_BOT_TOKEN=токен_от_BotFather
AI_PROVIDER=ollama
OLLAMA_HOST=http://127.0.0.1:11434
OLLAMA_VISION_MODEL=llava
OLLAMA_TEXT_MODEL=llama3.2
```

4. `start.bat` → **5** — проверка Ollama (должно быть «готова к работе»)
5. `start.bat` → **1** — `npm install` (первый раз)

## 3. Каталог товаров

Каталог хранится в `data/catalog-cache.json`.

- **Первый раз** (или когда нужно обновить): `start.bat` → **3** или в Telegram: `/reload`
- Дождитесь: `[catalog] Кэш сохранён: … позиций` (~5–10 мин, ~200 МБ)
- **При обычном запуске бота каталог не качается** — только локальный файл

Парсер: `https://outmaxshop.com/yml/all_new.yml`

## 4. VPS: Node.js

Если `npm: command not found`:

```bash
cd /root/zonadeck-deploy
chmod +x deploy/vps/*.sh
./deploy/vps/install-node.sh
```

## 5. Один раз: настройка деплоя

1. `setup-deploy-once.bat` — адрес сервера в `deploy.local.env`
2. `setup-ssh-once.bat` — пароль VPS **один раз**, дальше заливка без пароля

## 6. Обновление на VPS (после правок кода)

`update-vps.bat` → **1** (сборка + заливка + перезапуск)

Или: `start.bat` → **8**

Файл `.env` на сервере **не перезаписывается**.

## 7. SEO-новости (Yandex)

В `.env`:

```env
YANDEX_API_KEY=ваш_ключ_AI_Studio
YANDEX_FOLDER_ID=b1g...
```

Команда: `/seo Salomon XT-6` или кнопка **📰 SEO-новость**.

На VPS: `sync-yandex-env-vps.bat` (с Windows) или `ssh` на сервер → `nano .env` там.

Затем `pm2 restart zona-bot`.

## 8. Запуск бота

- `start.bat` → **2** или двойной щелчок по `run-bot.bat`
- Удобнее меню: `ZonaDeck.cmd`
- В консоли ожидайте:
  - `[ai] Ollama OK`
  - `Каталог локально: … позиций`
  - `Бот @ZonaDeck_bot запущен`
- **Окно не закрывайте**, пока бот работает

## 5. Telegram ([@ZonaDeck_bot](https://t.me/ZonaDeck_bot))

### Группа

- Пишите с **упоминанием** (выберите бота из списка, не просто текст): `@ZonaDeck_bot подбери белые Nike 43`
- Или команда: `/pick@ZonaDeck_bot белые Nike 43`
- Фото: подпись с `@ZonaDeck_bot` или ответ на сообщение бота
- **Если бот молчит и в консоли пусто:**
  1. [@BotFather](https://t.me/BotFather) → `/mybots` → ZonaDeck → **Bot Settings** → **Group Privacy** → **Turn off**
  2. Перезапустите бота
  3. В `.env` можно добавить `GROUP_ACCEPT_ALL=1` (все сообщения в группе)
- В консоли при сообщении в группе должно быть: `[tg] message chat=supergroup ...`
- Бот должен быть **запущен** на ПК (`start.bat` → 2)

### Личные сообщения

| Действие | Как |
|----------|-----|
| Фото → название и описание | Отправить **фото** (Zona / Ollama, 1–3 мин). Нет в каталоге → факты из интернета, стиль как в каталоге |
| Поиск по названию | `Nike Dunk` или `/find Nike Dunk` |
| Подбор 3 товаров | `подбери белые 42 зима` или `/pick …` |
| Статус | `/status` |
| Обновить каталог | `/reload` |
| Справка | `/start` |

Карточка товара: **фото, название, описание, цена**, ссылка (если есть в каталоге).

## 8. Частые проблемы

| Проблема | Решение |
|----------|---------|
| Ollama не отвечает | Запустить приложение Ollama в трее |
| Не хватает моделей | `ollama pull llava` и `ollama pull llama3.2` |
| Каталог не найден | Один раз: `/reload` или `start.bat` → 3 |
| `Promise timed out after 0 ms` | Перезапустить бота (обновлённый код) |
| Фото в карточке не пришло | Приходит текст и цена; сайт может блокировать прямую ссылку |
| `insufficient_quota` OpenAI | В `.env`: `AI_PROVIDER=ollama`, ключ OpenAI не нужен |
| start.bat сразу закрывается | Используйте `ZonaDeck.cmd` или PowerShell |
| Долго на фото | Нормально для локальных моделей |
